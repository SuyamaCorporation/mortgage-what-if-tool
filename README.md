## 住宅ローン「もしも」シミュレータ

繰り上げ返済額・金利変動・返済期間短縮の3変数をリアルタイムにシミュレーションするローン戦略ツール。

### 機能
- 基本入力スライダー: 借入金額・金利・返済期間
- 元利均等・元金均等 切り替え
- 月々返済額・総返済額・総支払利息をリアルタイム表示
- 繰り上げ返済シミュレーション: 毎月追加額スライダー → 期間短縮年数・利息節約額を表示
- 元金残高推移グラフ（Canvas 2D）: 繰り上げあり vs なし 重ね描き
- 金利変動試算: 現在/+0.5%/+1.0%/+2.0% の4シナリオを並列比較

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- Canvas 2D API（元金残高推移グラフ）
- 純粋JS計算エンジン（元利均等・元金均等）
